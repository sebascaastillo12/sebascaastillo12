# Sebastián Castillo Pujols

**Blockchain security researcher · Technical founder**

I research smart contract and cross-chain protocol security through Immunefi bug bounty programs. I build reproducible proofs of concept, test them against deployed code on local forks, and check whether recovery paths actually work. I also build and ship software through S33 Capital AI.

## Security research

- **Livepeer:** Reproduced a migration failure affecting delegator fee recovery with a Foundry test on an Arbitrum fork. Checked alternate recovery paths.
- **Axelar Network:** Built application-level Go tests to evaluate resource accounting on a pinned release. Checked reproducibility across three independent test runs.
- **Testing:** Ran 1,350+ fuzz scenarios in one protocol investigation and documented the negative result. On a separate target, tested nine of 18 hypotheses with runnable proofs of concept.

I work with Solidity, Foundry, Go, and Python. My research covers vault accounting, oracle freshness, governance, liquid staking, and cross-chain messaging.
