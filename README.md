# Sebastián Castillo Pujols

**Smart Contract & Protocol Security Researcher · Technical Founder**

I investigate how smart contracts and cross-chain protocols behave when assumptions about state, permissions, or transaction ordering break. In my independent bug bounty research through Immunefi, I build reproducible tests on local forks to establish who can trigger a failure, what changes, and whether recovery is possible.

## Selected security research

| Investigation | What I did |
| --- | --- |
| **Livepeer · Delegator fee recovery** | Reproduced a migration failure affecting delegator fee recovery with Foundry on an Arbitrum fork and tested alternative recovery paths. |
| **Axelar Network · Resource accounting** | Built application-level Go tests to evaluate resource metering on a pinned release and checked reproducibility across three runs. |
| **Protocol invariant testing** | Ran 1,350+ fuzz scenarios in one investigation without reproducing an invariant violation. On a separate target, tested nine of 18 hypotheses with runnable proofs of concept. |

**Research areas:** Vault accounting, oracle freshness, governance, liquid staking, and cross-chain messaging.  
**Tools:** Solidity, Foundry, Go, and Python.
